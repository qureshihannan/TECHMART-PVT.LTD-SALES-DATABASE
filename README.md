# 🛒 TechMart – Sales Database Management System (SQL)

## 📌 Project Overview

TechMart is a SQL-based sales database project designed to manage and analyze the data of an e-commerce business. The project focuses on organizing customer information, product details, sales transactions, and payment records to support efficient data retrieval and business analysis.

The database demonstrates the practical application of SQL concepts to solve real-world business problems and generate meaningful sales insights.

## 🎯 Project Objectives

- Design a structured relational database for an e-commerce business.
- Store and manage customer, product, sales, and payment-related information.
- Retrieve meaningful business insights using SQL queries.
- Analyze sales performance using aggregate functions and grouping.
- Apply joins, subqueries, and date/time functions to solve business questions.
- Practice advanced SQL techniques for data analysis.

## 🛠️ Tools & Technologies

- **SQL** – Database creation, data manipulation, and analysis
- **Relational Database Concepts** – Tables, primary keys, and foreign keys
- **SQL Queries** – Joins, subqueries, aggregate functions, and filtering

## 🗂️ Database Structure

The project uses six related tables to organize sales and e-commerce data.

| Table | Purpose |
|---|---|
| Customers | Stores customer names, cities, email addresses, and phone numbers |
| Products | Stores product names, categories, prices, and stock quantities |
| Categories | Organizes products into categories |
| Sales | Stores sales transaction details |
| Payments | Stores payment-related information |
| Additional project table | Supports the remaining database functionality |

*Note: Update the table names and descriptions to match your actual six-table schema.*

## 📊 Business Questions Explored

The database can be used to answer questions such as:

1. Which products have the highest prices?
2. How many customers are registered in each city?
3. What is the average price of products in each category?
4. Which product categories contain the most products?
5. How can information from multiple tables be combined using joins?
6. How can subqueries identify products or records that meet specific business conditions?
7. How can aggregate functions summarize business data?
8. How can date and time functions support transaction analysis?
